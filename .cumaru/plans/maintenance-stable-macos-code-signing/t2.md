# T2 — Provision the production signing identity

## What to do

Provide an operator-invoked macOS script that creates one long-lived self-signed Code Signing
identity outside CI, exports a password-protected PKCS#12 file, preserves an encrypted offline
backup, and uploads the required Actions secrets.

## Context

The production identity signs official releases of GoogleChatDeno.app. It is unrelated to passwords
stored by the installed application. Any local signing Keychain must be dedicated and temporary;
do not modify the user's login Keychain, existing credentials, or trust settings.

## Implementation

1. Create scripts/provision_macos_signing_identity.sh for deliberate local execution on macOS.
2. Require the needed tools, authenticated GitHub access, and the intended repository
   rntgspr/google-chat-deno before creating production material.
3. Use restrictive permissions and a dedicated temporary directory outside the repository.
4. Generate the persistent Code Signing certificate and private key, export an encrypted PKCS#12,
   and create separate passwords for that export and the temporary CI signing Keychain.
5. Require an encrypted offline backup of the identity and recovery credentials outside the repository.
   Cleanup must never delete the only recoverable copy.
6. Display the exact repository and secret names and request confirmation before uploading
   MACOS_CERTIFICATE_P12, MACOS_CERTIFICATE_PASSWORD, and MACOS_KEYCHAIN_PASSWORD through gh standard
   input. Base64-encode the PKCS#12 without printing secret values.
7. Provide short maintainer usage and recovery instructions alongside the provisioning script;
   explain that the certificate is generated once and reused for every official release.
8. Clean up temporary signing material on success, failure, and interruption while preserving backup.

## Done when

- [x] The provisioning script and maintainer instructions are implemented.
- [x] The production identity has an encrypted backup at the operator-selected location and its Actions secrets are provisioned.
- [x] Temporary signing material is cleaned up without touching user credentials.
